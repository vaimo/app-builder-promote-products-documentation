# PromoteProducts — Adobe App Builder Newsletter & AI Promotion Extension

An Adobe App Builder extension for Adobe Commerce (Magento) that replaces and enhances the default Magento newsletter email functionality with AI-powered promotional email and landing page generation, user list segmentation, and scheduled email delivery via SendGrid.

---

## Overview

PromoteProducts extends the Magento Admin with a full promotional mailing suite:

- **AI-generated email templates** — structured promotional emails created via OpenAI GPT-4 based on selected products, cart price rules, and targeting context
- **AI-generated landing pages** — full HTML landing pages generated by AI and publishable directly to Magento CMS Pages
- **User list segmentation** — subscribers are synced from Magento via an event listener and organized into named lists
- **Scheduled email delivery** — emails are scheduled to specific list + template combinations and delivered by a scheduled OpenWhisk action using SendGrid
- **Magento Admin UI integration** — React-based SPA embedded in Magento Admin via Adobe UIX extensibility, accessible from the sidebar and from the product grid mass-action menu

## Features

| Feature | Description |
|---|---|
| Customer sync | `observer.customer_save_commit_after` event syncs subscribers to App Builder DB |
| User lists | Group subscribers into custom lists; assign/remove users per list |
| Newsletter templates | CRUD for HTML email templates; manual or AI-generated |
| AI email generation | OpenAI GPT-4 generates structured promotional email content per product |
| AI image generation | OpenAI DALL-E generates product promotional images |
| AI landing page | OpenAI GPT-4 generates complete landing page content + full HTML |
| Scheduled emails | Schedule a template to a list with a send date; processed by cron action |
| SendGrid delivery | Emails sent via SendGrid with configurable sender identity |
| Commerce data | Product catalog via GraphQL; cart price rules via REST API (OAuth 1.0a) |
| CMS page publish | AI-generated landing pages published directly to Magento CMS Pages |
| App configuration | All sensitive keys managed via Adobe Commerce App Management UI |

## Prerequisites

**For merchants installing from Adobe Exchange:**
- Adobe Commerce 2.4.5 or later (PaaS or SaaS)
- Admin UI SDK (`magento/commerce-backend-sdk`) **3.3.1 or later**
- Adobe Commerce Eventing (`magento/commerce-eventing`) **1.9.0 or later**
- An OpenAI account with API key
- A SendGrid account with a verified sender identity

## Installation

This app is distributed as a **non-downloadable** app on Adobe Exchange. Merchants install it directly from Exchange — no CLI or file access is required.

For the full step-by-step installation and configuration guide, see [docs/INSTALLATION.md](docs/INSTALLATION.md).

### Post-installation configuration

After installation, open **Magento Admin → System → App Management → Promote Products** and enter:

| Field | Description |
|---|---|
| **Commerce Base URL** | Base URL of your Commerce store (e.g. `https://your-store.com/`) |
| **OpenAI API Key** | OpenAI secret API key (stored encrypted) |
| **OpenAI Model** | Model name, default `gpt-4` |
| **SendGrid API Key** | SendGrid API key with Mail Send permissions (stored encrypted) |
| **SendGrid From Email** | Verified sender email address |
| **SendGrid From Name** | Sender display name |

## AI Generation Workflows

See [docs/AI_GENERATION.md](docs/AI_GENERATION.md) for full details.

### Email Template Generation
1. Select a product from the catalog (GraphQL)
2. Optionally select a cart price rule (REST)
3. Optionally set event name, target audience, product link
4. Invoke `ai-generate-promotion-text` → structured JSON returned
5. Edit sections in the rich-text UI (Quill editor)
6. Optionally generate a product image via `ai-generate-image`
7. Preview assembled HTML email
8. Save to `newsletter_templates` collection

### Landing Page Generation
1. Same product/rule inputs as above
2. Invoke `ai-generate-landing-page-content` → structured JSON
3. (Alternatively: `ai-generate-landing-page-html` → full HTML, then `ai-extract-structured-data` to parse it)
4. Edit all sections in dedicated editors (hero, benefits, features, testimonials, FAQ, pricing, CTA)
5. Preview rendered HTML
6. Either export HTML or publish directly to Magento CMS Pages via the `cmsPage` POST operation
7. Optionally invoke `ai-regenerate-landing-page-html` after editing structured data to refresh the HTML

### `app.config.yaml`

- Main configuration file that defines an application's implementation.
- More information on this file, application configuration, and extension configuration
  can be found [here](https://developer.adobe.com/app-builder/docs/guides/appbuilder-configuration/#appconfigyaml)

#### Action Dependencies

- You have two options to resolve your actions' dependencies:

  1. **Packaged action file**: Add your action's dependencies to the root
     `package.json` and install them using `npm install`. Then set the `function`
     field in `app.config.yaml` to point to the **entry file** of your action
     folder. We will use `webpack` to package your code and dependencies into a
     single minified js file. The action will then be deployed as a single file.
     Use this method if you want to reduce the size of your actions.

  2. **Zipped action folder**: In the folder containing the action code add a
     `package.json` with the action's dependencies. Then set the `function`
     field in `app.config.yaml` to point to the **folder** of that action. We will
     install the required dependencies within that directory and zip the folder
     before deploying it as a zipped action. Use this method if you want to keep
     your action's dependencies separated.
